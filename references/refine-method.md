# 精炼方法详解

## 核心原则

**精炼不是摘要。**

| 对比项 | 精炼 | 摘要 |
|--------|------|------|
| 信息量 | 完整保留 | 概括删减 |
| 表达风格 | 保留原话感觉 | 改成书面语 |
| 对话节奏 | 保留互动痕迹 | 抽取核心观点 |
| 个人特色 | 保留说话人风格 | AI总结风格 |

---

## 精炼四原则

### 1. 去口水词

删除无意义填充词：
- "嗯""呃""啊""那个""就是""然后""所以说"
- 重复表达（"这个这个这个"）
- 纯语气词（"wow""哈哈"）

**例外**：如果"嗯""好了""这样啊"是对话互动的一部分，承载回应功能，就保留。

判断方法：去掉后对话是否断了？断了 → 保留；没断 → 可删。

### 2. 纠正识别错误

ASR（语音识别）常见错误类型：

| 错误类型 | 示例 | 判断方法 |
|----------|------|----------|
| 同音字错 | "李小来"→"李笑来" | 人名/品牌名对照 |
| 近音字错 | "拉格"→"RAG" | 上下文推断 |
| 中英混读 | "克 code"→"Claude Code" | 行业术语背景 |
| 方言误识 | "等宝宝出来"→"等防爆出来" | 逻辑是否通顺 |

**两条判断规则**：

**规则一：放在上下文里是否合逻辑？**
- 这词出现在这个话题里正常吗？
- 不正常 → 替换成同音/近音的行业术语 → 通顺就改
- 例："千文"→"千问"、"ICO"→"SEO"、"等宝宝出来"→"等防爆出来"

**规则二：去掉它对话是否中断？**
- 去掉后上下两句仍然完整连贯 → 大概率是噪声，可删
- 去掉后语义断了 → 承载信息，保留或纠正
- 例："wow!"→可删；"我们自己做的主攻"→可能是方言，保留

**处理原则**：
- ✅ 能确定原文的 → 改掉
- ✅ 不确定的 → 标注 `[疑似误识，待确认]`
- ❌ 不直接删除不确定的内容

### 3. 精炼表达

不是改成书面语，是让表达更清晰：

| 操作 | 正确做法 | 错误做法 |
|------|----------|----------|
| 删除废话 | 删除"不瞒你说""说实话""其实吧"等无信息量开场白 | 删除核心观点 |
| 结构化 | 用粗体标题、列表组织 | 改成AI总结风格 |
| 合并重复 | 合并同一观点的多次表达 | 概括删减信息 |

**精炼表达示例**：

原文（口语风格，有废话）：
> 不瞒你说，新客户要么是我们实际出去接触一个厂家，人家做了我的线觉得还好，然后会介绍其他厂家给我们。就像小竹环保，也是以前我们高层有一个厂家，在你们隔壁，小竹环保是你们厂家的老板推给我们的，这是一种模式。还有，因为我自己有一个抖音号，抖音上面有时候也会有客户询价过来，但不多。还有就是以前用过我们线的工地也好、单位也好，他们会因为那个品牌打电话打到公司，就这样吧。

精炼后（保留原话感觉，结构清晰）：
```
新客户来源有三种渠道：

**老客户推荐**：实际接触厂家做好后，老客户会介绍新客户。如小竹环保由隔壁厂家老板推荐。

**抖音询价**：抖音号偶尔带来询价，数量不多。

**品牌口碑**：用过我们产品的工地/单位会通过品牌电话主动联系。
```

### 4. 通顺修正

机械清理（去口水词+纠错）后，**必须通读全篇修正语义不通的句子**。

**为什么需要这一步？**
ASR 转写常残留语法断裂的句子——去完口水词后表面干净了，但读起来仍不通。必须做语义层面的重构。

**修正对象**：

| 问题类型 | 原文示例 | 修正后 |
|----------|---------|--------|
| 残句/碎句 | "交给我后台的。这一块的话就比较重要" | "代理别人的系统，不会给你看交付后台" |
| 语序混乱 | "我们是一套的打的。多模态" | "多模态我们是一套打包的" |
| 读不通 | "千系统就是千篇百律都是差不多的" | "洞察环节各系统大同小异" |
| 无关噪声串入 | "我家孩子。没办法，不好直接那个" | 直接删除 |

**验收标准**：
- ✅ 中文母语者通读不应停顿皱眉
- ✅ 每句话在上下文中有完整语义
- ❌ 机械去口吃后就认为完成了

**与「精炼表达」的区别**：
「精炼表达」是提升清晰度（结构化、去废话）。「通顺修正」是修复破损——让碎句变完整句、让不通的变通。前者是优化，后者是修补。

## ASR 归属错误判断

说话人标签错误（ASR 归属错误）：

**判断方法**：
- 第一人称视角："我们厂""我们自己发明的""我们行业"
- 如果出现在不该出现的人口中 → 大概率是归属错误
- 例：工厂方说"我们厂"是对的，如果销售方说"我们厂"就错了

**处理**：
- 根据对话上下文重新归属
- 不确定 → 标注并让用户确认

## 保留什么

**必须保留**：
- 人名、机构名、时间、数据
- 观点立场、态度倾向
- 关键决策、行动项
- 对话互动节奏
- 下游用途需要的证据：客户顾虑、销售回应、现场验证、承诺边界、下一步安排

**可选删除**：
- 纯口水词（嗯呃啊那个就是然后）
- 重复表达
- 无信息量开场白
- 与主线无关的插曲（接电话、查快递、生产杂事、人事闲聊等）

**销售复盘场景例外**：
看似闲聊的内容，如果能解释客户组织关系、决策链条、信任来源、销售推进条件，就不能整段删除；应提炼成业务补充。详见：[销售复盘型逐字稿整理](sales-review-transcripts.md)。

**禁止**：
- 添加原文没有的信息
- 改变观点立场
- 改成书面语摘要
- 删除有信息量的内容
