# 逐句检查方法

## 核心检查问题

**逐句检查两个问题：**

1. **「读起来通顺吗？」** — 不通顺就重写，这是底线
2. **「这是原话的感觉吗？」** — 通顺的基础上保持原味

---

## 检查清单

### 保留优先级

| 优先级 | 内容类型 | 处理 |
|--------|----------|------|
| P0 必留 | 人名、机构名、时间、数据 | 绝对保留 |
| P0 必留 | 观点立场、态度倾向 | 绝对保留 |
| P0 必留 | 关键决策、行动项 | 绝对保留 |
| P1 优先留 | 对话互动节奏 | 尽量保留 |
| P2 可删 | 纯口水词（嗯呃啊那个就是然后） | 可删 |
| P3 可删 | 重复表达、无信息量开场白 | 可删 |

---

## 互动保留判断

### 判断方法

**问题：删掉这句话，对话是否断层？**

| 答案 | 处理 |
|------|------|
| 是，对话断了 | ✅ 保留 |
| 否，对话连贯 | ⚠️ 可删（再检查信息量） |

### 示例分析

**案例1：互动回应**

原对话：
```
A：你觉得这个方案怎么样？
B：嗯...我觉得还行吧。
```

分析：
- "嗯"承载"正在思考"的互动信号
- 删掉 → B 的回应变得生硬
- 结论：**保留**

精炼后：
```
A：你觉得这个方案怎么样？
B：嗯，我觉得还行。
```

**案例2：纯口水词**

原对话：
```
A：然后呢？
B：然后就是，那个，我们就开始做那个事情了。
```

分析：
- "然后就是""那个""那个"都是纯口水词
- 删掉 → "我们就开始做这件事了"仍然完整
- 结论：**可删**

精炼后：
```
A：然后呢？
B：我们就开始做这件事了。
```

## 原话感觉判断

### 判断方法

**问题：精炼后这句话，听起来像是说话人会说的话吗？**

| 答案 | 处理 |
|------|------|
| 是，听起来像原话 | ✅ 精炼合格 |
| 不太像，有点书面化 | ⚠️ 调整回更口语 |
| 完全不像，变成AI风格 | ❌ 精炼过度，回滚 |

### 常见过度精炼

| 过度精炼 | 原话风格 |
|----------|----------|
| "我们需要评估可行性" | "你看这事儿能不能干" |
| "这是一个重要议题" | "这事儿挺重要的" |
| "我持保留意见" | "我觉得不太行" |

**原则**：保留说话人的个人风格，不要改成职场书面语。

---

## 检查流程

### Step 6 执行流程

1. 精炼完成后，从头开始**朗读式通读**（默读也行，但必须逐句过）
2. 每句先问：「读起来通顺吗？」
   - 不通 → 重写（比保留原话更重要）
3. 再问：「这是原话的感觉吗？」
   - 不像 → 调整回更口语
4. 发现遗漏的口水词 → 继续精炼
5. 发现互动断层 → 补回互动词

### 检查反馈

```
🔄 逐句检查中...

检查点：
- [1/10] 第1段：保留"嗯"作为互动信号 ✅
- [2/10] 第2段：调整"我们需要评估"→"你看这事儿能不能干" ✅
- [3/10] 第3段：删除重复"然后然后" ✅
...
- [10/10] 检查完成

✅ 逐句检查完成
- 调整数量：{X} 处
- 保留互动词：{Y} 处
```

## 不确定时的处理

### 标注待确认

不确定是否该删的句子：

```
{精炼后的句子}[?] 原话是"XXX"，不确定是否该删
```

汇总到精炼稿底部：

```
---
⚠️ 精炼疑点（请用户确认）：

1. 第X段："这句话"是否该删？原话是"XXX"
2. 第Y段："嗯"是否保留？删掉后对话可能断层
---
```
