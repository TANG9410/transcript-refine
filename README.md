# Transcript Refine

把中文逐字稿整理成能回看、能核对的成稿。适合商务交流、客户访谈、会议复盘和课程学习。

这是供 Codex、Claude Code 等 AI 助手使用的 **skill**。AI 负责理解和整理，Python 工具负责原文落盘、对照、检查和保存。它接收已有文字转写；音频需要先完成转写。

## 选择你需要的成稿

| 形式 | 适用需求 | 处理方式 |
|---|---|---|
| 交流实录稿 | 保留当时怎么聊的 | 按原顺序保留问答、语气、数字和限定条件，默认轻度精炼 |
| 复盘纪要稿 | 看清事实、分歧和下一步 | 按主题提炼，每项判断与行动能回到原文核对 |
| 学习整理稿 | 把课程变成详细学习材料 | 保留推理、案例、数据、适用条件和实质问答 |

形式明确时直接执行；商务或多人对话未明确形式时，先让你三选一。无法确认的人物、术语和数字会保留疑点。

## 安装

需要支持 skill 的 AI 助手和 **Python 3.10+**。本地文本流程仅使用 Python 标准库，不需要 Get笔记账号。

Windows PowerShell：

```powershell
git clone https://github.com/TANG9410/transcript-refine.git
cd transcript-refine
.\install.ps1 -Target Codex
# Claude Code 改用：.\install.ps1 -Target Claude
```

安装前可加 `-WhatIf` 查看目标；已有同名目录时停止，避免覆盖。也可以下载仓库 ZIP 后解压，再执行安装脚本。

macOS / Linux 可手动复制到对应助手的 skills 目录，方法见 [安装与使用](INSTALL.md)。

## 怎么用

安装后重新打开助手会话，提供原始逐字稿文件，再发送：

> 使用 $transcript-refine，把这份客户访谈整理为交流实录稿。轻度精炼，保留问答过程、数字和不确定表达，保存为本地 Markdown。

也可以指定：

> 使用 $transcript-refine，整理这份会议逐字稿，给我复盘纪要和有原文依据的行动项。

> 使用 $transcript-refine，把这堂课整理为详细学习材料，保留讲解逻辑、案例和问答。

默认交付本地 Markdown，原始材料保持不变。只有明确要求并自行配置后，才通过可选 Get笔记接入读取或保存笔记。

## 本次更新

当前版本 **4.1.2**，产品名称统一为 `transcript-refine`。

- 使用 `prepare → review → deliver` 统一准备、复核和交付。
- 复核对照绑定真实原文与当前成稿；改稿后需要重新复核。
- 人物归属不稳定时记录证据，保留未决问题。
- 交流实录保留会议时间、参会人员、原始笔记三项表头；缺失时明确标注。

Python 检查通过表示结构、证据绑定及复核记录满足要求，**不代表语义已被程序自动核实**。关键数字、承诺和人物归属仍需阅读原文核对。

## 数据与边界

仓库不包含维护者的私人术语表、录音、客户逐字稿、凭证或运行记录。公开示例和离线测试不代表真实客户事实。

本地 Python 流程不主动联网；AI 助手对输入材料的处理取决于你选择的产品及其设置。不要把敏感原文或配置文件提交到仓库、Issue 或 PR。
