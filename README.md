# transcript-refine-v3

用于把 Get笔记录音、网页转写或用户原文整理为可验证的中文成稿。

## 支持的交付形态

- 交流实录稿：保留对话过程、人物关系与关键证据。
- 复盘纪要稿：提炼结论、行动项和销售/合作风险。
- 学习整理稿：整理课程、讲座和知识型长独白。

对于商务、客户、销售、合作、访谈和多人对话，未明确交付形态时，skill 会先推荐交流实录稿并等待确认；多人内容先锁定说话人，再生成最终稿。

## 依赖

- Python
- 具备 Get笔记读取/写入能力的宿主环境（仅在选择 Get笔记交付时需要）

## 使用边界

- 事实源仅限 `audio.original`、`web_page.content` 或用户提供的原文；不以 AI 摘要替代原始内容。
- 默认新建精炼稿，不改原始笔记。
- 保存后必须 read-back，并核对标题、正文长度和规范化 SHA256。
- 不包含账号、Token、客户原始逐字稿或本机运行状态。

详细工作流、分支合同和脚本用法见 `SKILL.md`、`references/` 与 `scripts/`。
